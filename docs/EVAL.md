# 평가

## 무엇을 측정하는가
| 지표 | 정의 | 계층 | 목표 |
|------|------|------|------|
| {예: Recall@10} | {정답 문서가 상위 10개 안에 든 질의 비율} | {검색} | {예: ≥ 0.85} |
| {예: 응답 정확도} | {Judge가 정답으로 판정한 비율} | {응답} | {목표} |
| {예: P95 지연} | {질의 1건 end-to-end 95분위 지연} | {시스템} | {예: ≤ 5s} |

## Golden set
- 위치: `{eval/golden/...}`
- 규칙: 라벨은 사람이 검수해 고정한다. 모델이 생성한 정답을 검수 없이 golden으로 쓰지 않는다.
- 구성: {질의 유형별 문항 수}

## 실행
```bash
{make eval}
```

- 이전 결과 대비 회귀가 있으면 원인을 적는다. 수치를 고치려고 golden set을 바꾸지 않는다.
